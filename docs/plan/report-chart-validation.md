# 验证图表数据与报告接收效果

[改动计划](README.md) · P1 · 状态：本地实现与合成验证，待真实预览和候选发布

## 现在是什么情况

新增来源隔离的图表 API，报告保存曲线，独立 SVG/HTML 详情；用户反馈后正文自动插图已关闭，详情改为紧凑、单图切换；午睡、厂商七日负荷区间、readiness 修订、训练摘要字段及显式注释/活动核对/Hevy CSV 接口已经进入候选源码。当前行为和接口由[报告与渠道](../reports.md#曲线图与图表-api)、[数据合同](../data-contracts.md#图表事实合同)负责。

合成测试不证明真实设备返回这些字段，也不证明 PushPlus 接收端保留相对定位微图。浏览器截图命令成功，但本次会话模型无图像输入能力，未完成视觉验收。不在此宣称已经部署或更新历史真实报告。

## 接下来做什么

1. 发布前固定候选 SHA 并复核对应验证。多设备候选本地后端分组完成 2,983 项通过、17 项跳过；随后来源覆盖、别名冲突与空分期审查边界另做74项目标回归。quick、docs、package 通过；单进程 backend 首轮曾触及 600 秒预算，不能把该次超时记为通过。
2. 已只读核对设备目录显式别名，并生成11月1/2日私密三路预览；仍需用户确认每条来源与App一致，不能把这次只读预览当作发布完成。继续核对一份实际日报、晚报及上一完整周/月：心率缺口、压力稀疏点、Charge分项、睡眠午睡和Zepp负荷区间逐项对照App。未知来源不补图。
3. 多设备候选增加显式aliases和分来源band记录；确认旧记录需重解析的窗口，验证新旧scope不会并存重复。对本次新增表/字段按[部署流程](../deployment.md)生成并验证加法DDL和反向DDL，不重建或删除现库。旧日负荷和readiness需基于加密原始记录定向回放，确认差异再更新，不能用排版重算代替来源修正。
4. 图表先保留在详情，不恢复正文大图。以后确有阅读收益且用户确认再设计渠道图；PushPlus真实测试需另外明确授权，验证反馈链接、运输预算和最终接收状态。
5. 呼吸频率目前对 UTC 日桶做摘要，请求和归日需进一步与协议及 App 核对；未确认采样锚点和跨本地日裁切前，不将其宣称为已修正的本地夜间指标。
6. Hevy使用脱敏的实际导出样式核对日期、单位、同日多场歧义、显式映射、关联防重复。当前缺少解除/更改关联；需要纠正时先开发带revision的显式操作，不要求用户重新导入绕过。

## 怎样算完成

- 本地目标、quick/backend/docs/package检查通过或经具体问题修复重验，不能把超时写成通过。
- 候选服务器schema、加载路径、API读取、worker分析和历史快照状态验证通过。
- 真实设备字段、报告图表以及PushPlus接收效果分别有用户确认；无数据项保持未知。
- 显式写入的身份、幂等、修订历史与分析重算经实际输入验收，无未授权通知或Hevy账户连接。
- 发布并完成必要验收后删除本计划，将仍有效规则留在主责文档。
