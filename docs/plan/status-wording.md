# 推送里的系统状态改成人话

[改动计划](README.md) · P0

## 为什么

报告页眉会按 `report_state` 显示“数据已更新，显示上一版结果”这类系统状态（`src/vitalis/intelligence/report_rendering.py`），用户读不懂，也不知道该做什么。10/12 的真实晨报和晚报页眉都标着“部分报告”，只因为当天还没结束，看起来像出了故障。

## 改什么

- 推送只在状态影响阅读时说一句人话：看到的是哪个时刻的数据、缺什么、什么时候会更新，例如“今早的睡眠还没同步完，下面是 07:10 的版本”。
- 纯技术状态（排队、重算中、快照版本）只留在 API 和 `GET /api/reports/{kind}/state`。

## 验收

- 合成测试覆盖 `current`、`stale`、`queued`、`running`、`failed` 五种状态的推送文案。
- 先给用户发一份真实样例确认，再部署。
