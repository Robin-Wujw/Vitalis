# 身体信号预警接入晨报

[改动计划](README.md) · P1

## 为什么

两个以上身体信号两晚同时偏离个人范围时建议降低强度，规则已在离峰批处理里影子运行（见[数据合同](../data-contracts.md)），还没统计过误报率。

## 改什么

- 用 `vitalis shadow run --days 60` 补算历史，`vitalis shadow report body_signal --user <用户> --days 60` 列出每个预警日；用户逐日确认当时是否确实疲劳或不适，算出误报率。
- 误报率可接受、用户确认后，晨报在预警日提示降低强度（不做疾病判断）。

## 验收

- 误报统计给用户看过并确认；接入后真实样例发给用户确认再上线。
