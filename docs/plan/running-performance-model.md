# 跑力与训练评分的独立验证及启用

[改动计划](README.md) · P1 · 相关：[当前模型合同](../data-contracts.md)、[力量真实验收](strength-muscle-mapping.md)、[发布 SOP](../deployment.md)

## 待完成的目标

当前 CS、固定心率表现 E、后程保持 D、个人基准候选指数及单次回顾的实现边界见数据合同。能力估计与候选总分保持未验证资格；本条负责独立效果验证与启用，不能因合成数据恢复了参数就删除。

## 准备独立数据

- 在私有环境取得有明确来源的独立比赛/测试成绩，区分 5 km、10 km、设备、场地、气候与能力水平。普通轻松跑不得伪装成最大能力标签，厂商 VO2max 或 QRun 分数不作唯一真值。
- 保存特征截止时间、获取时间、模型及基线版本、拟合训练 ID 和目标成绩 ID。拟合、调参、验收按日期分开；目标成绩不进入自己的特征。获取时间未知时不声称已完成严格历史回放。
- 不同设备或环境缺乏重叠校验时分别验收；样本不足的组保留不足，不以混合后的平均结果掩盖。

## 验证任务

1. **CS 绝对成绩预测**：用 tools/validate_running_performance.py --mode race 检查独立 5/10 km 预测；每种目标距离另报 MAE、偏差、中位及 90 分位百分误差、区间覆盖率。候选标准为中位误差不超过 5%、90 分位不超过 10%、不劣于近期简单成绩基线，且有足够独立样本。这是产品目标，不是文献保证。
2. **RPI 相对变化**：用 --mode relative 比较同一人相对速度的未来变化。预先固定 28±7 天预测窗口，按日期划分 70% 训练候选与后续测试，并剔除结果跨越测试起点的训练样本；至少三十项训练、二十项测试。相对 CS 与候选 RPI 使用同复杂度校准，报告误差与方向判断；没有稳定增益时只保留单项解释。
3. **敏感性与不确定性**：核对 42 天窗口、21 天衰减半期、片段时长和 60/25/15 权重；按场次或相应时间块抽样，量化设备、环境和方案变化的影响。D 的上限和 h0 的冻结协议不能在回放后随结果挑选。
4. **单次评分**：审核事前目标明确的恢复、轻松、间歇、长跑案例，检查缺数据、暂停、加量、配速变化与减量日的含义。候选数值只衡量目标执行，不宣称健康收益或伤病概率；公开总分需经真实案例审核后单独启用。
5. **发布**：先提供用户可审阅的真实预览，再按 SOP 隔离验收候选 SHA。模型验证不足时可以发布回顾和已有事实，但不把候选指数接入训练强度决策。

## 既有负荷规则审核

单独回放当前周增量和负荷比调度规则，检查其是否诱导追量或被误读为安全阈值；在新模型接入决策前完成。禁止把 0.8–1.3、每周 10% 或任何单个分数解释为确定的伤病安全区间。

## 验收与完成条件

运行跑步、加载、趋势、决策、快照、目标关联、报告与通知测试及 tools/check.py all --ci、git diff --check；保留聚合误差、分组失败率、模型版本和启用范围。工具不打印逐场记录，数据和报告只在私有验收环境使用。缺少独立成绩时继续保留本计划和未验证状态，不改分段、标签或阈值凑通过。

## 研究依据

- [Smyth 2020：日常训练估算 CS](https://pubmed.ncbi.nlm.nih.gov/32472926/)：超过 25,000 名跑者，预测仍有误差；群体关联不保证个人准确性。
- [Lipková 2025：场地 CS 测试综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC11933073/)：协议影响估计，不能将平均配速直接视为能力。
- [Anderson 2026：CS 与 D′ 测量及应用](https://pmc.ncbi.nlm.nih.gov/articles/PMC13388421/)：方法尚未统一，D′ 不是直接实测无氧容量。
- [Buchheit 2014：心率与训练状态](https://pmc.ncbi.nlm.nih.gov/articles/PMC3936188/)：需标准化情境、测量误差及训练背景。
- [Hunter 2025：耐久性测量方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC12576026/)：心率解耦不等于完整生理耐久性，不能直接推脱水。
- [INTERLIVE 2022：可穿戴 VO2max 有效性](https://pubmed.ncbi.nlm.nih.gov/35072942/)：个人一致性界限较宽。
- [Impellizzeri 2020：ACWR 概念与方法问题](https://pubmed.ncbi.nlm.nih.gov/32502973/)：不将负荷比包装成因果伤病预测。
