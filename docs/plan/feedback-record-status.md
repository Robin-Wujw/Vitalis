# 反馈页别把没记录说成没完成

[改动计划](README.md) · P1 · 状态：本次核查发现，待开发

## 现在是什么情况

**没有同步到训练记录，不等于用户没有训练；有一场同类训练，也不等于完整执行了计划。**

反馈页目前按当天是否有与主要安排同类型的训练，显示“主要安排已完成”或“还没有完成主要安排”。没有训练记录时也会进入“未完成”分支。记录可能尚未上传，类型匹配也没有核对时长、组数等计划内容，因此两种措辞都过于肯定。

这和一次性链接能否正常提交是两个问题，不能靠用户成功提交一次反馈就关闭。

## 接下来做什么

1. 将展示依据明确为“有没有记录到与安排同类型的训练”，不把它当作用户确认或完整计划的完成状态。
2. 无记录或无法判断时说明“暂未记录到匹配训练”；有匹配类型时说明“已记录到同类训练”，不要写“计划已完成”。没有适用安排时不强行判断。
3. 修正服务返回含义与页面措辞的不一致；反馈页不写入推荐完成状态，也不由用户打开页面或保持沉默推断任何行为。

## 怎样算完成

- 合成测试覆盖无计划、无训练记录、不同类型记录、同类型但时长或组数不匹配，以及晚到训练。
- 页面只说记录能证明的事实，缺失不当否定，类型相同不当作完整执行。
- 一次性、过期、用户隔离和明确提交才写入等现有规则不受影响；反馈目标测试和 `uv run --locked --extra dev python tools/check.py backend` 通过。
- 用户可见措辞经预览确认并按发布流程上线；与[手机实际提交验收](feedback-tags.md)分别记录，互不代替。
