# 日常报告每句都给结论

[改动计划](README.md) · P0 · 相关：[推送里的系统状态改成人话](status-wording.md)、[日常报告的自动验收](report-acceptance.md)

## 为什么

10/12 用真实数据渲染的晨报和晚报里，有几句普通人看不懂或会误读：

- “训练负荷较前一周期变化 +59.2%”：没说这是正常递增还是过量，也没说该怎么做。
- 晚报写“活动时长 0 分钟”，同一天又列着 32 分钟户外跑，两条事实互相矛盾。
- 睡眠只和个人近 28 天比：连续 4 天 1 点后入睡，基线本身也是晚的，报告从不指出。

## 改什么

- 每个数字配一句判断（正常、偏高或偏低，以及依据）；负荷变化说明它相对近 4 周平均的位置和建议。
- 厂商日汇总与已记录训练矛盾时（例如活动时长小于当天训练时长），不展示该汇总值。
- 周报加入作息规律度（入睡时间波动、睡眠中点）和“成年人 7–9 小时、作息稳定”的绝对参照，只在周报里温和提示，不在每天的晨报里反复说。

## 验收

- 合成测试：日常报告里的每个数字都有判断；矛盾的汇总值不出现；入睡时间连续晚于阈值时，周报出现一句提示。
- 真实样例先给用户确认，再部署。
