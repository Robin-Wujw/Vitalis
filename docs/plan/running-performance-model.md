# 先验证跑步能力预测，再决定是否启用

[改动计划](README.md) · P1 · 状态：候选模型已有，需补验证工具和独立成绩；未启用

## 现在是什么情况

**系统已经能试算跑步能力，但还没有证明这些数字对真实成绩有用。**

当前候选模型结合短时持续速度、固定心率下的表现、长跑后程保持情况，尝试描述能力及其变化。它仍是“影子模型”：可以留作研究，不展示为正式跑力，也不控制训练强度。单次训练回顾已有，公开总分未启用。现有计算规则见[跑步能力模型](../data-contracts.md#跑步能力影子模型)。

[验证工具](../../tools/validate_running_performance.py)已有比赛预测和相对变化两种模式，但只完成部分检查。跑通工具或在合成数据上还原参数，都不能证明模型已验证。

## 接下来做什么

1. **准备独立成绩**：使用有来源的 5 km、10 km 比赛或测试成绩，记录设备、场地、气候和能力水平；这些成绩不能参与自己的模型拟合。普通轻松跑不能当最大能力测试，厂商 VO₂max 或 QRun 分数不能作为唯一正确答案。
2. **先补齐验证报告**：工具已能计算部分误差，但还缺按距离的完整误差表、预测区间覆盖率、设备和环境分组，以及相对变化的方向判断。补齐后再做实际验收，不能只交一份总体平均值。
3. **回答两个不同问题**：一是能否预测真实比赛用时；二是在相同预测窗口内，合成指数能否比相对 CS 更准确地预测个人速度变化。后者没有稳定提升，就只保留单项解释。
4. **检查参数是否可靠**：改变窗口、衰减、片段长度和权重后，结论不应随意翻转；设备和天气差异要分开看。
5. **单独审核单次评分**：用训练前目标明确的恢复跑、轻松跑、间歇和长跑，检查缺测、暂停、加量、配速变化及减量日是否被合理对待。评分评价计划执行，不代表健康收益或伤病概率。
6. **最后决定怎么发布**：先提供真实预览。验证不足时可以继续展示已有事实和回顾，但不能把候选跑力接进强度安排。

## 怎样算完成

- 拟合、调参和验收按时间分开，验收成绩未泄漏进特征；保存特征截止时间、获取时间、模型版本、基线版本、拟合训练标识和目标成绩标识。
- 计划启用的每种距离、设备和环境都有足够独立样本及误差结果；不足的组明确写不足，不用混合平均值掩盖失败。
- 下述预测、相对变化和参数检查完成，实际评分案例经过审核；记录未通过项和具体启用范围。没有达到标准就继续保持未验证，而不是调标签凑通过。
- 回放检查现有周负荷安排，确认不会为了追目标诱导加量；任何负荷比或分数都不称为伤病安全线。
- 跑步、数据加载、趋势、决策、快照、目标关联、报告和通知目标测试，以及 `uv run --locked --extra dev python tools/check.py all --ci`、`git diff --check` 通过。
- 按[发布流程](../deployment.md)完成预览、候选版本验收和明确的启用改动。工具输出“通过”不自动启用模型或总分。

## 验证细节

这部分保留实现所需标准；不影响先读懂上面的工作目标。

### 指标是什么意思

| 名称 | 在这里表示什么 |
| --- | --- |
| CS（临界速度） | 从不同持续时间片段估计的速度能力，不是某次平均配速。 |
| E | 在固定参考心率下的跑步表现；不能靠换成更高心率制造进步。 |
| D | 稳态长跑后程相对前程的速度—心率表现，不等于完整生理耐久性。 |
| RPI | 合成的个人相对变化候选指数，目前不是正式评分。 |
| 简单基线 | 用近期成绩作出的简单预测；复杂模型至少应比它更有用。 |

### 比赛用时预测

运行工具的 `--mode race`，对每种拟启用的目标距离分别审核：

- 至少 20 个合格独立样本。
- 绝对百分误差的中位数不超过 5%，90 分位不超过 10%，平均绝对百分误差不劣于简单基线。它们是候选产品标准，不是文献保证。
- 报告平均绝对误差（平均差多少秒）、有方向的偏差（偏快还是偏慢）、中位与 90 分位误差，以及真实用时落进预测区间的比例。

**工具现状**：已经检查部分日期和重复样本条件，并按距离给出样本数、中位误差和 90 分位误差；平均绝对误差和偏差目前只在总表里，区间覆盖率和设备、环境分组仍需补齐。工具不负责收集独立成绩，也不能证明所有获取时间都满足历史回放要求。

### 个人相对变化

运行 `--mode relative`：提前固定 28±7 天预测窗口，按日期取前约 70% 作校准、后续作测试，剔除结果跨入测试起点的校准样本；剔除后至少保留 30 项训练样本和 20 项测试样本。相对 CS 与 RPI 使用同复杂度的校准方法。

**工具现状**：上述时间拆分和同复杂度校准已有，能比较平均误差；变化方向、分组误差及增益是否稳定仍需补齐。不能仅凭一次平均误差略低就启用合成指数。

### 参数、来源与评分边界

- 核对 42 天窗口、21 天衰减半期、片段时长和 60/25/15 候选权重；按训练场次或时间块重复抽样，检查结论对设备、环境和方案变化是否敏感。
- 合成时 D 的上限及参考心率 h0 的固定规则要预先确定，不能看完验收结果再挑最有利的设置。
- 没有重叠校验的设备或环境分别验收；获取时间未知时，不声称已完成严格的历史回放。
- 单次跑步与力量共用[评分规则](../data-contracts.md#单次训练评分的共同规则)，但跑步案例单独审核。当前周增量与负荷比规则也要回放；0.8–1.3、每周 10% 等数字都不是确定的安全区间。
- 私有验收只保存必要的汇总误差、失败率和版本。工具不打印逐场记录，真实数据和完整报告不进入仓库。
