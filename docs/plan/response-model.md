# 个人反应模型与预测校准

[改动计划](README.md) · P3 · 前置：[一键反馈与行为标签](feedback-tags.md)、[准备度评分与 HRV 状态](readiness-score.md)

## 为什么

报告只描述发生了什么，不知道建议对这个人是否有效；没有预测，也就没法评估系统准不准。

## 改什么

- 建个人反应模型：负荷、睡眠和行为标签分别如何影响次日 HRV、静息心率和主观精力。
- 用模型校准准备度权重，并预测明早的恢复情况。
- 每周离线回放，跟踪四个指标：次日 HRV 预测误差、预警误报率、计划执行率、反馈有用率。
- 月报展示“系统对你的预测准不准”。

## 验收

- 累计至少 60 天带反馈的数据后才启用；样本不足时月报说明还在积累。
- 预测误差优于“明天和今天一样”的朴素基线才上线。
