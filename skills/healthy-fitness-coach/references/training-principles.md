# 训练原则

这是一般教育，遵守[入口边界](../SKILL.md)与[安全边界](safety-boundaries.md)。适用性未确认时不把普通成人参数变成个人课表；个人趋势与已保存推荐只由 Vitalis API 提供。

## 先理解目标，再看形式

有氧侧重持续活动耐受，阻力训练帮助发展力量与肌肉，功率训练关注快速产力和技术质量。能量系统并非互斥，“无氧”不等于所有力量动作，也不等于必须练到力竭。

可问：“你想理解力量和增肌的区别，还是有氧与力量怎样搭配？”如果只是概念问题，无需索取体重或训练日志。

一般健康成人的公共活动参考是逐步接近每周 150～300 分钟中等强度有氧（或 75～150 分钟高强度及等效组合），并有至少两天主要肌群活动。这是教育性人群参考，不是用户首周任务或个人达标判断；不能把不足的量集中补回来。[依据与局限](evidence-and-uncertainty.md)同样适用。

## 负荷、技术与渐进

- 先让动作可控制、可重复，再讨论增加负荷。膝主导、髋主导、推、拉与核心稳定是组织动作的方式，不意味着每次都必须齐全。
- RIR 表示自觉还能完成多少次，RPE 表示主观用力程度；它们不是精密仪器。保留余力有助于兼顾技术与疲劳，不必用每组力竭证明努力。
- 渐进通常一次改变少量变量，如重复次数、负荷或总量；更多并不必然更有效。降载和中断后保守回归不代表失败，不以加倍训练补偿漏训。
- 有氧与阻力可以互补。若主要目标不同，顺序和疲劳分配的取舍也不同；不应笼统说有氧“吃掉肌肉”。高强度间歇和爆发练习不是新手必需品。

## 只用于说明的假设示例

假设示例，仅解释概念，不代表适合你：某个虚构计划规定 3 组、每组 8～12 次，先保持技术并逐渐增加次数，达到区间上沿后才讨论小幅加重。这叫双进阶；不能用用户上次重量自行算出今天该举多少。

全身或上下肢分化只是分配练习机会的不同结构；选择应考虑时间和恢复等条件。本包可以解释取舍，不编译周计划、不生成日程、不判定用户应该进阶或覆盖 Vitalis 已保存推荐。
