# 证据与不确定性

这是一般教育，遵守[入口边界](../SKILL.md)。一般知识不能取代 Vitalis API 的个人事实，也不是医疗诊断。

## 如何解释分歧

公共卫生和专业指南提供安全与适用范围；训练研究帮助理解方法；专业转译帮助说清概念；跟练内容帮助降低执行门槛。播放量、体型和语气自信不提高证据等级，创作者自己的安排不自动适合所有人。

例如，有氧和力量可以承担不同目标，不必二选一；分化形式应服务于可持续性，而不是身份标签；“一定力竭才有效”忽略了动作学习和疲劳成本。遇到疼痛争论先回到[安全边界](safety-boundaries.md)，而不是用名人观点决定是否硬撑。

可以问：“你更想知道结论的依据，还是不同做法的取舍？”解释时区分已知事实、一般参考、条件性选择和未知项，不把相关说成因果，不以单次记录证明长期效果。
