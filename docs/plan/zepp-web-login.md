# 不用插件，在电脑网页上连接 Zepp

[改动计划](README.md) · P0

## 为什么

插件配对要开发者模式、粘贴地址和配对码。网页登录页（电脑版布局）、两步登录、`login_token` 续期、续期失败时经 PushPlus 发重新登录链接，以及经 ZeroTier 私有网络访问的入口都已上线（见 [Zepp](../zepp.md) 和[运维](../operations.md)）。2026-10-14 14:03 用户用真实手机号和密码在电脑网页上登录成功，新令牌带 `login_token`，首次 180 天回填已开始。

## 改什么

- 确认首次回填完成、之后的晨报和晚报正常。
- 下次凭据失效时确认续期接口在真实账号上可用；不可用就去掉续期，只保留重新登录链接。
- 网页登录稳定两周后（2026-10-28）删除浏览器插件、书签入口和 `VITALIS_PAIRING_ALLOWED_ORIGINS`。

## 验收

- 回填完成后晨报、晚报正常；日志、数据库明文和响应里没有密码或令牌。
- 插件和相关配置删除后，`tools/check.py all --ci` 通过。
