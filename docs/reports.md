# 报告与渠道

Vitalis 报告从已保存快照读取事实、比较、分析和建议。缺失观测保持缺失；只有会改变当前结论的缺口才在对应位置提示。报告不要求用户回复，也不把投递状态当作健康反馈。

## 报告周期

| 类型 | 默认范围 | 重点 |
| --- | --- | --- |
| 晨报 | 目标日前一夜和可用晨间事实 | 先看睡眠，再说明当天重点；可选指标缺失不阻塞其它事实。 |
| 日报 | 目标本地日 | 总览当天活动、睡眠和已记录训练；训练明细只展示真实组次和单位。 |
| 周报 | 目标日所在周之前的上一完整本地周 | 解释持续变化及其主要来源，不把缺失日当休息日。 |
| 月报 | 目标日所在月之前的上一完整本地月 | 使用正确日均或频率比较方向，不只比较不同月长的总量。 |

周报默认周一至周日，月报按本地日历月。明确标记为 `rolling` 的结果才称“近 7 日”或“近 28 日”；不能把滚动窗口称自然周/月。`period_start`、`period_end` 描述统计范围，`as_of` 或生成时间描述数据看到的时刻。

日报内活动只能与相同截止时刻的历史比较；日内值不能直接和完整昨日比较后写成下降。睡眠、活动、训练和反馈分别保留来源、单位和可用日数。没有训练记录不等于休息日，未知动作不补名称，`12 / 10 / 8` 组次不改成三个相同组。

## 阅读报告

先看标题、日期和数据截止时刻，再看关键指标和变化。分析只解释数据支持的变化，建议只引用已有决策或事实。可选 HRV 缺失时省略 HRV，不添加全局限制段落；某一比较数据不足时只在该比较处说明，活动分析仍可继续。

报告 JSON 保留版本、`analysis_run_id`、`data_quality`、事实、特征、趋势、事件和决策字段。Markdown 和保守的 inline HTML 由同一展示模型分别直接渲染；HTML 不是把 Markdown 再转换一遍，也不重新查数据库或计算健康指标。两种输出的事实、单位、日期和缺口应保持一致。数据不足的报告仍应直接可读，但不提供没有证据的训练建议。

## 本地导出与 API

从仓库根目录、已有 demo 数据库执行：

```powershell
uv run --locked --extra dev vitalis report morning --user demo --day 2026-10-07 --format markdown --output .\morning.md
uv run --locked --extra dev vitalis report weekly --user demo --day 2026-10-07 --format html --output .\weekly.html
```

导出是纯预览，要求输出路径不存在。HTTP 使用 `GET /api/reports/{kind}?day=YYYY-MM-DD` 和 Bearer 令牌读取已保存快照；GET 不启动同步或分析。没有快照返回 404。API 当前还提供 `evening`、`weekly-briefing` 和 `monthly-briefing` 的读取路径，字段以 `/openapi.json` 为准。

## PushPlus

PushPlus 是单向、只读的推送出口。消息模板必须与正文类型一致；当前实现明确选择模板，HTML/Markdown 在真实渠道验证前不能互相冒充。HTTP 200 只表示 HTTP 请求完成；只有业务 `code=200` 且返回有效供应商消息标识时才记录 `accepted`，业务失败不能记为 accepted。最终送达、失败和未知分别记录；超时或响应丢失保持 `uncertain`，不盲目重试。投递记录不会改变目标完成、反馈或健康状态。

本地浏览器预览不等于 PushPlus 实际接收端验证；真实 PushPlus 联调当前未完成，不在文档中宣称已验证。发送前应检查实际 `content` 是否被代码围栏、JSON 二次序列化、字面量换行、错误模板或整体 HTML 转义包裹。用户备注和动作名称必须安全转义。

## Hermes

Hermes 是可选的对话入口，不是报告生成依赖。默认先短答用户当前问题；只有缺少关键输入时才追问。只有用户明确意图和授权成立时，才通过独立反馈或目标用例写入；发送、打开、沉默和未回复都不改变目标或健康反馈。真实 Hermes 环境联调当前未完成，Skill 的离仓 mock 合同不能代替真实调用。

## 调度与状态

晨报、晚报、同步和可选周/月报都由独立 worker 负责；调度时间、时区和启用开关的唯一配置说明见[运维](operations.md)。投递成功、失败、延期和不确定状态与分析快照分离；迟到数据只刷新尚未发送且仍合资格的意图，不把样式更新当成历史补发。
