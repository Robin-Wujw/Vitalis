# 身体信号异常预警

[改动计划](README.md) · P1 · 相关：[准备度评分与 HRV 状态](readiness-score.md)

## 为什么

静息心率升高、HRV 下降，同时呼吸频率或皮温升高，常常先于生病或过度疲劳出现，这是可穿戴数据最有价值的提醒之一。所需的静息心率、夜间 HRV、皮温偏差、呼吸频率和血氧都已在同步，只是呼吸频率、皮温和血氧还停在影子模式。规则只用各信号自己的个人正常区间，不必等准备度评分。

## 改什么

- 两个以上信号同时偏离个人正常区间时，晨报提示降低强度；例如连续两晚静息心率高出个人基线、皮温偏高且 HRV 下降。
- 先影子运行并统计误报率；误报率可接受、用户确认后再进晨报。判定函数（`detect_body_signal_warning`）已有，还没接进每日分析、也没有保存影子结果。
- 只提示“信号异常、建议降强度”，不做疾病判断。

## 验收

- 合成测试：单一信号偏离不触发，两个以上同时偏离才触发。
- 影子期的误报统计给用户看过再上线。
