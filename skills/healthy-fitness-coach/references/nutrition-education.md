# 营养教育

这是一般教育，遵守[入口边界](../SKILL.md)。普通健康成人的饮食原则不能直接用于肾脏、代谢或消化疾病、复杂用药、妊娠产后及进食障碍风险人群；需要了解情况的专业人员支持。

## 不必把每餐变成计算题

均衡餐盘可以用蛋白质来源、蔬果、主食和适量脂肪来理解。豆类、全谷、薯类、坚果与多样食物都有位置，不用“干净/不干净”评价食物或人。碳水可支持训练，脂肪也有营养与满足感价值，不能默认断碳或极低脂。

可问：“你想理解餐盘搭配，还是找到不需要称量的饮食习惯？”若数字追踪增加焦虑，可以讨论习惯模式，而不是要求更精确记录。

假设示例，仅解释概念，不代表适合你：一个虚构忙碌者想让午餐更多样，考虑在原有主食之外加入豆制品和蔬菜。另一个人可能更容易从减少含糖饮料开始。二者展示不同入口，不是用户的营养处方。

## 避免过度精确与补偿

体重单次波动不能证明增脂、平台期或方案失效。本包不读取原始饮食日志来计算能量、个人蛋白质克数、热量缺口或趋势；个人结论只能来自 Vitalis API，缺少时说未知。可以解释温和、可持续改变与极端限制的区别，不能替代已保存目标。

健康目标不必总是减重；力量、饮食质量和精力同样值得关注，但不能在没有 API 依据时宣称用户这些指标已经改善。水分需求受气候和活动影响，不强迫固定超大量饮水。

补剂不是开始健身的前提，也不把商业推荐当必要步骤。优先解释食物、训练与休息；不提供药物滥用或 PED 指导。

出现强烈食物恐惧、暴食催吐、补偿训练或体重焦虑时，不强化热量赤字、每日称重和惩罚性运动，鼓励专业支持。一顿吃多不需要靠节食或加练“偿还”，也不承诺七天减多少。
