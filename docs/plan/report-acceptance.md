# 日常报告的自动验收

[改动计划](README.md) · P0

## 为什么

10/09 合入的改动把晨报从 25 行撑到 677 行（真实数据 2.6 万字），1,549 个测试全部通过：测试守护的是数据契约，没有检查用户真正读到的内容，当时甚至有测试要求正文逐条输出来源和覆盖。现在只有零星断言检查个别字样（例如 q 值）不出现。

## 改什么

- 晨报、晚报、日报各定可见文字上限和必有区块，写成测试：用合成的长历史数据渲染，超过上限，或缺少关键记录、今天的重点/明日重点就失败。
- 断言日常报告里不出现 28/60/90 天窗口、T+N 训练反应、q 值和逐信号来源清单。
- 报告样例（`docs/examples/reports`）变化时，提交说明附上可见文字长度的前后对比。

## 验收

- 把 10/09 的渲染方式（把公开投影逐条铺开）接回去时，新测试失败。
- `tools/check.py all --ci` 包含这些测试。
