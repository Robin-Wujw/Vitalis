# 力量训练映射与评分的真实验收

[改动计划](README.md) · P1 · 相关：[数据合同](../data-contracts.md)、[Zepp 目录](../zepp.md)、[报告与渠道](../reports.md)

## 待完成的目标

当前重量容量、肌群组数估算、180 天个人参照、并列方向建议与单次回顾的规则以数据合同为准。本条只保留正式启用评分和扩展精细映射前仍需完成的验收，不将厂商图示或候选分数描述为已经验证的生理结论。

## 映射与真实记录

- 在私有环境抽查实际常用动作、同名器械变式和用户纠错，核对当前规范身份、原始区域数组、部位展示及组序；不把 APK、真实记录或响应放入提交。
- 对缺少文字解释的人体图区域补充可审阅的语义证据；取得证据前保留未知。规范动作的扩展按实际使用优先审核，不按名称猜齐目录覆盖率。
- 明确哪些记录能支持工作组剂量；厂商部位参考不提高用户确认覆盖。单只/双只、辅助、自重、左右侧、热身与工作组的实际口径分别验收，缺口不得补零。
- 在更多真实动作与长期记录中审核集中训练识别阈值、最近阶段的代表性及辅助组系数敏感性；已实现逐完整周比较和缺失降级，真实效果仍需持续审核。验证晚到数据、反馈和映射更新不会重复计组或重复推送。

## 评分与健康边界

- 使用用户明确关联、生成于开跑或力量训练之前的计划。目标完成 40%、剂量适配 40%、执行 20% 仅作候选，缺必需维度时不重分权重；公开总分在审核前保持空值。
- 准备代表性审核案例：维持、减量、未完成、高努力、缺 RIR、自重与部分明细。检查候选分数是否符合真实目标，是否诱导加重、加组或追求力竭。传感器缺测不算训练表现差。
- 逐组或明确范围的 RIR 反馈可用性需要实际验证；整场 RPE 不代替每组余力。相同努力资格才比较估算力量，不能把更接近力竭当作能力提高。
- 用户可见变化按发布 SOP 先提供真实预览确认，再部署。无 schema 变化保留现库，不为显示映射备份或换库。

## 验收

以合成或脱敏数据运行目录、解析、持久化、ProfileLoader、力量、周报、决策、报告与通知目标测试，以及 tools/check.py backend、docs、package 和 git diff --check。真实预览仅在私有环境进行。评分启用前记录审核案例、固定权重、容差、版本与未通过项；合成测试通过不能替代真实效果验证。

## 研究依据

- [ACSM 2026：健康成人力量训练处方](https://pmc.ncbi.nlm.nih.gov/articles/PMC12965823/)：137 篇综述，重视目标、持续参与及个性化；不把增肌剂量设为所有人的健康最低任务。
- [Pelland 2026：周组数与频率](https://pubmed.ncbi.nlm.nih.gov/41343037/)：间接半组为统计建模方式，不是精确受力系数。
- [Robinson 2024：接近力竭程度](https://pubmed.ncbi.nlm.nih.gov/38970765/)：连续剂量关系仍有探索性与 RIR 估计限制。
- [Schoenfeld 2019：等训练量下的频率](https://pubmed.ncbi.nlm.nih.gov/30558493/)：不以固定分化或固定间隔认定更优或已恢复。
- [Nuzzo 2024：次数与 %1RM](https://pubmed.ncbi.nlm.nih.gov/37792272/)：动作及个体差异需要保留。
- [Schumann 2022：有氧与力量并行](https://pubmed.ncbi.nlm.nih.gov/34757594/)：不假设跑步必然损害增肌；关注目标及疲劳安排。
- [Saw 2016：主观反馈与训练反应](https://pubmed.ncbi.nlm.nih.gov/26423706/)：不以客观信号代填局部感受。
