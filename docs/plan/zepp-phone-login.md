# 不用插件，在手机上连接 Zepp

[改动计划](README.md) · P0

## 为什么

插件配对要开发者模式、粘贴地址和配对码，只能在电脑上完成。手机登录页、两步登录、`login_token` 续期、续期失败时经 PushPlus 发重新登录链接，以及经 ZeroTier 私有网络访问的入口都已上线（见 [Zepp](../zepp.md) 和[运维](../operations.md)），但都还没用真实账号走过。

## 改什么

- 用户在手机上打开 `vitalis connect zepp --user <用户> --push` 发来的链接，用真实账号登录一次；确认首次回填和首份报告正常。
- 下次凭据失效时确认续期接口在真实账号上可用；不可用就去掉续期，只保留重新登录链接。
- 真实登录稳定两周后删除浏览器插件、书签入口和 `VITALIS_PAIRING_ALLOWED_ORIGINS`。

## 验收

- 真实账号在手机上走通一次，日志、数据库明文和响应里没有密码或令牌。
- 插件和相关配置删除后，`tools/check.py all --ci` 通过。
