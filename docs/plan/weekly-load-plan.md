# 周负荷目标与训练计划

[改动计划](README.md) · P1

## 为什么

训练计划原来是通用模板，与本周已经练了多少无关。周负荷目标（近 4 周周均 × 1.05）、急慢性负荷三档、晨报按剩余负荷分配今天的跑步时长、晚报的本周进度都已实现（规则见[数据合同](../data-contracts.md)），用户看到的报告变了，需要先确认真实样例。

## 改什么

- 把用真实数据渲染的晨报和晚报发给用户确认；按反馈调整措辞或参数。
- 力量训练日给出今天适合练的肌群，依赖已上线的肌群负荷和新鲜度；样例确认后再加。

## 验收

- 真实样例经用户确认后上线；合成测试覆盖周初、周中补齐、已经超量三种情况（`tests/test_weekly_load.py`）。
