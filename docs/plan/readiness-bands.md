# 准备度分数段按个人分布校准

[改动计划](README.md) · P1

## 为什么

0–100 准备度和 3 个因素已进晨报关键记录，但训练安排仍跟按信号计票的恢复结论走。固定分数段（≥ 67 较好、< 34 偏低）下，2026-09-14 至 10-13 的分数在 30–66 之间，30 天里只有 2 天“偏低”、0 天“较好”；用户确认状态差的 10-01 至 10-03 分数 39–46，按分数段是“一般”，而计票结论是“受抑制”（建议恢复）。直接用分数段代替计票会在这些日子给出更重的安排。

## 改什么

- 用 `vitalis shadow report readiness --user <用户> --days 60` 的逐日分数，按个人分布定分数段（例如个人 20/80 分位），并把 Zepp 晨起 Charge（已在晨报显示，`recovery.wake_charge*`）作为第二个信号：它抓单日明显偏低（10-01、09-17 都是 67，低于个人 20 分位 72），准备度抓连续几天的偏离（10-01 至 10-04）；对照用户确认过的状态差日子和计票结论。
- 新分数段在状态差日子上不比计票更激进、用户确认后，DecisionEngine 用分数段代替计票。

## 验收

- 新分数段的逐日对比给用户看过并确认；合成测试覆盖各分数段的安排，真实样例发给用户确认后上线。
