# 一键反馈与行为标签

[改动计划](README.md) · P2

## 为什么

反馈、建议完成和纠错的记录都是 0 次：PushPlus 是单向的，Hermes 还没联调，接口有了却没有入口。没有主观标签，个人模型就学不到东西。

## 改什么

- 推送页加反馈入口：今天感觉 1–5 分、RPE、酸痛部位；行为标签：饮酒、晚餐晚、咖啡因、生病、出差。
- 入口用一次性签名链接，需要公网 HTTPS 入口（现在 API 只在本机监听）；也可以改走 Hermes 快捷回复。开工前和用户确认走哪条。
- 能从训练记录判断计划是否执行的，自动记录，不让用户手填。
- 反馈模型已有 `feeling_score`、`soreness_parts`、`behavior_tags` 字段，缺的是入口。
- 反馈仍只在用户明确提交时写入；打开、沉默不算反馈。

## 验收

- 合成测试：签名链接只能用一次、过期失效、不能写别人的数据。
- 真实环境提交一次反馈，确认进入对应日期的重算。
