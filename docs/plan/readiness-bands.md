# 准备度分数段接管训练安排

[改动计划](README.md) · P1

## 为什么

晨报显示的准备度（v2：HRV 昨晚与 7 日各半、7 日净睡眠负债、负荷正常区间中性、加入晨起 Charge；显示分数 70 为个人平常水平，< 60 偏低、≥ 85 较好）已和用户体感对齐：60 天回放里与晨起 Charge 的秩相关 0.68，10-01 为 43 分、10-14 为 70 分。但训练安排仍跟按信号计票的恢复结论走。

## 改什么

- 用 `vitalis shadow report readiness --user <用户> --days 60` 列出逐日显示分数、分数段和计票结论，与用户逐日核对不一致的日子（尤其分数 ≥ 60 而计票为“受抑制”的日子）。
- 用户确认后，DecisionEngine 用分数段（< 60 受抑制、≥ 85 较好）代替计票。

## 验收

- 逐日对比给用户看过并确认；合成测试覆盖各分数段的安排，真实样例发给用户确认后上线。
