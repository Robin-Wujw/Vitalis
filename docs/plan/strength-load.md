# 力量容量与肌群负荷

[改动计划](README.md) · P2

## 为什么

力量训练已有逐组的次数和重量，但晚报只列动作。Bevel 2026-09 版新增了肌群负荷（短期对长期：Productive / Maintaining / Overtraining）和肌肉新鲜度。

## 改什么

- 力量卡加总容量（组 × 次 × 重量）、估算 1RM 和个人纪录；重量单位未知的组不计算。
- 给 `src/vitalis/adapters/zepp/data/strength_exercises.json` 里的动作补主要/次要肌群映射。
- 按肌群计算短期与长期负荷的比值，给出三档状态和新鲜度。

## 验收

- 合成测试：未知重量、未知动作、`12 / 10 / 8` 这类不等组次。
- 发真实样例给用户确认。
