# On-Demand Explanation

[简体中文](on_demand.md)

All runtime user-visible output must be Chinese. After the user explicitly answers a profile question, write it with `tools/profile.py patch` and include the current revision. On a 409 response, read the profile again and do not overwrite other updates. A “why” question about today's training recommendation must use `workflows/daily_explanation.md`; this workflow must not fall back to `tools/analyze.py` or `tools/sync.py`.

For trend questions, use only TrendResponse; for recent changes, use only HealthEventResponse. Mention percentage change, slope, deviation, or duration in days only when the corresponding field exists. When multiple pieces of evidence exist, explain in Chinese that the judgment integrates multiple signals. Show Chinese limitations that could change the interpretation. Do not present correlation as causation or diagnose disease from a deviation. When answering about training content, repeat only `action.action_plan`; preserve the primary item, optional item, their relationship, evidence, dose, stop conditions, and validity period. Use all Chinese labels and never expose internal English codes in runtime output.

For training-response questions, use only TrainingResponse: clearly distinguish T+1/T+2/T+3, device streams, missing windows, and overlapping training. State recovery duration only when `recovery_hours` is non-null. For personal patterns, use only the median, MAD, sample size, coverage, and confidence from PersonalModel, and call them an “association” or “personal pattern,” never causation. For PersonalAssociation, repeat only `summary`, paired days, coverage, coefficient, strength, confidence, and limitations. Explain in Chinese what `association_only=true` means; do not choose thresholds, calculate significance, or promote a weak association to an action recommendation. For a timeline, describe sequence only from the returned typed summary; do not infer causation from temporal proximity.
