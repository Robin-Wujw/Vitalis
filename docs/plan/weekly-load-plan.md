# 周负荷目标与训练计划

[改动计划](README.md) · P1 · 前置：[日级特征表](daily-features.md)

## 为什么

训练计划是通用模板（例如“轻松跑 30–37 分钟”），与本周已经练了多少无关。Google Health 改用每周有氧目标、允许周内补齐；Bevel 用短期对长期负荷判断状态。

## 改什么

- 按用户目标和近 4 周负荷设每周负荷目标；晚报显示本周进度，今日负荷计入周目标。
- 急慢性负荷比分“提升 / 维持 / 过量”三档。
- 晨报的计划从周目标倒推：类型、时长、心率区间（由乳酸阈心率换算）和一句理由。
- 力量训练日给出今天适合练的肌群；依赖[力量容量与肌群负荷](strength-load.md)的肌群映射，映射完成前不给。

## 验收

- 合成测试：周初、周中需要补齐、已经超量三种情况给出不同建议。
- 发真实样例给用户确认后上线。
