# 数据流新鲜度监控

[改动计划](README.md) · P1 · 前置：[投递目标与漏发告警](delivery-alerts.md)

## 为什么

Zepp 的 HRV 端点和分钟心率端点目前解析为空，训练明细也受资源限制。数据流断了没人知道，只会表现为报告里某一项缺失。

## 改什么

- 每个数据流（睡眠、HRV、静息心率、活动、压力、训练、训练明细、密集心率）记录最后一次成功观测的时间和近 7 天覆盖。
- 超过预期间隔仍无新数据时自动补拉一次；补拉后仍缺，经投递告警的同一通道告警。
- 查清 HRV 和分钟心率端点为空的原因：修好解析，或在[数据合同](../data-contracts.md)里写明不可用。

## 验收

- 合成测试：某个流停更后，在预期间隔后触发一次补拉和一次告警。
- `GET /api/data-status` 返回每个流的新鲜度。
