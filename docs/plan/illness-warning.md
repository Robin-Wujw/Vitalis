# 身体信号异常预警

[改动计划](README.md) · P3 · 前置：[准备度评分与 HRV 状态](readiness-score.md)

## 为什么

静息心率升高、HRV 下降，同时呼吸频率或皮温升高，常常先于生病或过度疲劳出现。呼吸频率、皮温偏差和血氧现在只在影子模式采集。

## 改什么

- 两个以上信号同时偏离个人正常区间时，晨报提示降低强度。
- 先影子运行并统计误报率；误报率可接受、用户确认后再进晨报。
- 只提示“信号异常、建议降强度”，不做疾病判断。

## 验收

- 合成测试：单一信号偏离不触发，两个以上同时偏离才触发。
- 影子期的误报统计给用户看过再上线。
